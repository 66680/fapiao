# Security Policy

## Supported Versions

The latest released minor line is considered supported for security fixes.

## Reporting a Vulnerability

Please report security issues responsibly by email:

- security@your-domain.example

Do not open public GitHub issues for undisclosed vulnerabilities.

## Disclosure Process

1. Send a private report with reproduction details and impact.
2. We acknowledge receipt within 72 hours.
3. We triage severity and provide a remediation ETA.
4. After a fix is released, coordinated disclosure can proceed.

## Scope Guidance

Include:

- affected version/commit
- attack preconditions
- proof-of-concept steps
- expected vs actual behavior
